# الإدارة والموردون والمرتجعات

## الإدارة والموردون والمرتجعات

### حدود الاعتماد

| القرار              | الجهة المخوّلة          | الشرط                     |
| ------------------- | ----------------------- | ------------------------- |
| شراء روتيني         | المشرف المباشر          | حتى 20,000 دج             |
| شراء كبير أو عقد    | المدير التقني والمؤسس   | أكثر من 20,000 دج         |
| رفض دفعة واردة      | مشرف الجودة أو الإنتاج  | تجاوز AQL أو عيب حرج      |
| إيقاف الخط          | أي عامل ثم تأكيد المشرف | خطر سلامة أو عيوب ≥ 5%    |
| إعادة تشغيل الخط    | المشرف                  | قبول 95% من دفعة 100 وحدة |
| شطب أكثر من 50 وحدة | المشرف والمدير التقني   | توقيع مزدوج               |

يُلزم الاعتماد المزدوج لأي قرار يتجاوز 50,000 دج. كما يلزم للسلامة والعقود.

### تقييم الموردين

| المعيار            | الوزن | مصدر التقييم       |
| ------------------ | ----: | ------------------ |
| الجودة             |   40% | الرفض ونسبة العيوب |
| السعر              |   30% | عروض الأسعار       |
| الالتزام بالمواعيد |   30% | سجل الاستلام       |

**النتيجة:** `(الجودة × 0.40) + (السعر × 0.30) + (المواعيد × 0.30)`.

| التصنيف    |    النتيجة | المعاملة                 |
| ---------- | ---------: | ------------------------ |
| مورد أساسي |   8.0–10.0 | عقد 6–12 شهراً           |
| مورد بديل  |    5.0–7.9 | طلبيات محدودة وخطة طوارئ |
| مورد محظور | أقل من 5.0 | إيقاف التعامل            |

### مسار المرتجعات

1. سجّل رقم الدفعة، البيع، العطل، والجهة المستلمة.
2. افحص القطعة خلال 48 ساعة.
3. أصلح العطل البسيط أو اعزله للتحليل.
4. مرّر القطعة المُصلحة على تنظيف كيميائي وBurn-in لأربع ساعات.
5. أعدها للمخزون أو اشطبها خلال سبعة أيام عمل.

تُحفظ القطع قيد الفحص في **منطقة حجر** منفصلة. يوثق الشطب بالقيمة وسبب الخسارة والتوقيعات المطلوبة.
