# الإدارة والموردون والمرتجعات

## الإدارة والموردون والمرتجعات

### حدود الاعتماد

| الشرط                     | الجهة المخوّلة          | القرار              |
| ------------------------- | ----------------------- | ------------------- |
| حتى 20,000 دج             | المشرف المباشر          | شراء روتيني         |
| أكثر من 20,000 دج         | المدير التقني والمؤسس   | شراء كبير أو عقد    |
| تجاوز AQL أو عيب حرج      | مشرف الجودة أو الإنتاج  | رفض دفعة واردة      |
| خطر سلامة أو عيوب ≥ 5%    | أي عامل ثم تأكيد المشرف | إيقاف الخط          |
| قبول 95% من دفعة 100 وحدة | المشرف                  | إعادة تشغيل الخط    |
| توقيع مزدوج               | المشرف والمدير التقني   | شطب أكثر من 50 وحدة |

يُلزم الاعتماد المزدوج لأي قرار يتجاوز 50,000 دج. كما يلزم للسلامة والعقود.

### تقييم الموردين

| مصدر التقييم       | الوزن | المعيار            |
| ------------------ | ----: | ------------------ |
| الرفض ونسبة العيوب |   40% | الجودة             |
| عروض الأسعار       |   30% | السعر              |
| سجل الاستلام       |   30% | الالتزام بالمواعيد |

**النتيجة:** `(الجودة × 0.40) + (السعر × 0.30) + (المواعيد × 0.30)`.

| المعاملة                 |    النتيجة | التصنيف    |
| ------------------------ | ---------: | ---------- |
| عقد 6–12 شهراً           |   8.0–10.0 | مورد أساسي |
| طلبيات محدودة وخطة طوارئ |    5.0–7.9 | مورد بديل  |
| إيقاف التعامل            | أقل من 5.0 | مورد محظور |

### مسار المرتجعات

1. سجّل رقم الدفعة، البيع، العطل، والجهة المستلمة.
2. افحص القطعة خلال 48 ساعة.
3. أصلح العطل البسيط أو اعزله للتحليل.
4. مرّر القطعة المُصلحة على تنظيف كيميائي وBurn-in لأربع ساعات.
5. أعدها للمخزون أو اشطبها خلال سبعة أيام عمل.

تُحفظ القطع قيد الفحص في **منطقة حجر** منفصلة. يوثق الشطب بالقيمة وسبب الخسارة والتوقيعات المطلوبة.
