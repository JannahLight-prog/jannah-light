# الصيانة والسلامة

## الصيانة والسلامة

### برنامج الصيانة المرجعي

| المعدة        | الإجراء                          | الوتيرة              |
| ------------- | -------------------------------- | -------------------- |
| ماكينة الكبس  | فحص O-Ring وضغط الهواء           | أسبوعياً / يومياً    |
| حوض اللحام    | تنظيف وقشط أكسيد ومعايرة الحرارة | أسبوعياً / شهرياً    |
| موزع الغراء   | تنظيف الفوهة بـ Isopropanol      | كل 4 ساعات           |
| ماكينة الليزر | تنظيف العدسة وفحص الشفط          | أسبوعياً / شهرياً    |
| آلة التلميع   | تنظيف شفط الغبار                 | يومياً               |
| المولد وUPS   | تجربة المولد وفحص البطاريات      | أسبوعياً / كل 6 أشهر |

### قواعد السلامة الملزمة

* شغّل شفط الأبخرة قبل اللحام أو توزيع الغراء.
* ارتدِ القفازات الحرارية والنظارات والكمامة والمئزر.
* استخدم نظارات الليزر خلال التشغيل.
* اختبر سوار ESD يومياً. المقاومة المستهدفة تقارب 1 MΩ.
* لا تستخدم الماء أو البودرة قرب الأجهزة الكهربائية أو PCBs.

### استجابة الطوارئ

| الحدث           | الإجراء الفوري              | الاستمرارية                     |
| --------------- | --------------------------- | ------------------------------- |
| عطل الفرن       | أوقفه واعزله                | لحام يدوي وتجميع نهائي          |
| انقطاع الكهرباء | استخدم UPS ثم المولد        | إنتاج يدوي ومخزون الأمان        |
| رطوبة > 70%     | أوقف إدخال دفعات جديدة      | شغّل مزيل الرطوبة وافحص المخزون |
| حريق صغير       | افصل التيار واستخدم CO₂     | أخلِ المنطقة وسجّل الحادث       |
| إصابة عامل      | افصل التيار وقدّم الإسعافات | اتصل بالإسعاف عند الحاجة        |

### نظام 5S

نظّم المواد، وحدد مكان كل أداة، ونظّف يومياً. وحّد الإجراءات، ثم راقب الالتزام باستمرار.

يُنفذ تفتيش شهري للمعدات، مخارج الطوارئ، مطافئ CO₂، الإسعافات، منطقة الحجر، وحاويات النفايات. تُسلَّم النفايات الخطرة لجهة مرخّصة عند امتلاء الحاوية 80% أو كل 6–12 شهراً.
