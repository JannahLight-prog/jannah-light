# المصطلحات والمعايير المرجعية

| المعنى التشغيلي                                           | المصطلح |
| --------------------------------------------------------- | ------- |
| شحنات ساكنة قد تتلف المكونات. تُضبط بأساور وطاولات مؤرضة. | ESD     |
| حد القبول المسموح به للعيوب في العينة.                    | AQL     |
| إجراء تصحيحي ووقائي يمنع تكرار سبب العطل.                 | CAPA    |

| رمز يربط المنتج بالضمان والدفعة وسجل الصيانة.             | QR      |

### معايير مرجعية

* **ISO 9001:** توثيق العمليات والتحسين المستمر.
* **ISO 14001:** إدارة الأثر البيئي والنفايات.
* **ISO 45001:** إدارة السلامة والصحة المهنية.
* **IEC 60598-1:** متطلبات السلامة والعزل لمنتجات الإنارة.
* **IEC 61340:** التحكم في الشحنات الكهروستاتيكية.
* **IEC 62471:** السلامة الضوئية ومخاطر الضوء الأزرق.
* **LM-80:** بيانات الحفاظ على فيض رقائق LED.
* **RoHS:** تقييد المواد الخطرة في المكونات.

تُراجع الشهادات والاختبارات مع جهات اعتماد مؤهلة قبل استخدامها كادعاء تسويقي أو تنظيمي.
