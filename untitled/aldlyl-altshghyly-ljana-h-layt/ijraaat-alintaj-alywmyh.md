# إجراءات الإنتاج اليومية

## إجراءات الإنتاج اليومية

تعمل الوردية من 08:00 إلى 17:00. الاستراحة من 12:00 إلى 13:00.

{% stepper %}
{% step %}
### ابدأ الوردية

اعقد اجتماعاً مدته 15 دقيقة. وزّع الأدوار. راجع أهداف اليوم وسجل الأعطال والسلامة.
{% endstep %}

{% step %}
### جهّز المحطات

نظّف الطاولات. جهّز صواني المكونات. شغّل حوض اللحام قبل 20 دقيقة. افحص سوار ESD.
{% endstep %}

{% step %}
### حضّر PCB

افحص المسارات والمكونات بصرياً. نظّف الأكسدة الخفيفة بـ Isopropanol 99%. استخدم ملاقط مضادة للشحنات الساكنة.
{% endstep %}

{% step %}
### نفّذ اللحام والتنظيف

اقشط الأكسيد قبل كل غمر. سخّن اللوحة 3–5 ثوانٍ. اغمرها 2–4 ثوانٍ. أخرجها بزاوية 45°. اتركها تبرد دقيقتين. نظّفها خلال 30 دقيقة.
{% endstep %}

{% step %}
### اجمع واختبر وغلّف

ثبّت الناشر بوزن غراء 0.15–0.20 غ. اكبس القاعدة. نفّذ الفحص البصري والكهربائي. ضع ختم `QC Passed` بعد القبول.
{% endstep %}

{% step %}
### أغلق الوردية

سجّل الإنتاج والرفض واستهلاك المواد والأعطال. نظّف الآلات. افصل التيار وجهّز المحطات لليوم التالي.
{% endstep %}
{% endstepper %}

### ضوابط اللحام

| زمن الغمر | نطاق الحرارة | نوع السبيكة            |
| --------: | -----------: | ---------------------- |
| 2–4 ثوانٍ |    240–260°C | Sn63/Pb37              |
| 2–4 ثوانٍ |    260–280°C | SAC305 خالية من الرصاص |

لا تستخدم مروحة لتبريد PCB. يمنع ذلك التشققات المجهرية.

### هدف الإنتاج

ينتج العامل 28–30 بطاقة PCB سليمة يومياً. تُقاس دورة الإنتاج من بداية التجميع حتى التغليف. أوقف الخط عند بلوغ عيوب الوردية 5%.
