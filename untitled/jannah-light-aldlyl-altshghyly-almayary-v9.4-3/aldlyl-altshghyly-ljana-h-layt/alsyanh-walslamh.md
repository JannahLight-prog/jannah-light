# الصيانة والسلامة

## الصيانة والسلامة

### برنامج الصيانة المرجعي

| الوتيرة              | الإجراء                          | المعدة        |
| -------------------- | -------------------------------- | ------------- |
| أسبوعياً / يومياً    | فحص O-Ring وضغط الهواء           | ماكينة الكبس  |
| أسبوعياً / شهرياً    | تنظيف وقشط أكسيد ومعايرة الحرارة | حوض اللحام    |
| كل 4 ساعات           | تنظيف الفوهة بـ Isopropanol      | موزع الغراء   |
| أسبوعياً / شهرياً    | تنظيف العدسة وفحص الشفط          | ماكينة الليزر |
| يومياً               | تنظيف شفط الغبار                 | آلة التلميع   |
| أسبوعياً / كل 6 أشهر | تجربة المولد وفحص البطاريات      | المولد وUPS   |

### قواعد السلامة الملزمة

* شغّل شفط الأبخرة قبل اللحام أو توزيع الغراء.
* ارتدِ القفازات الحرارية والنظارات والكمامة والمئزر.
* استخدم نظارات الليزر خلال التشغيل.
* اختبر سوار ESD يومياً. المقاومة المستهدفة تقارب 1 MΩ.
* لا تستخدم الماء أو البودرة قرب الأجهزة الكهربائية أو PCBs.

### استجابة الطوارئ

| الاستمرارية                     | الإجراء الفوري              | الحدث           |
| ------------------------------- | --------------------------- | --------------- |
| لحام يدوي وتجميع نهائي          | أوقفه واعزله                | عطل الفرن       |
| إنتاج يدوي ومخزون الأمان        | استخدم UPS ثم المولد        | انقطاع الكهرباء |
| شغّل مزيل الرطوبة وافحص المخزون | أوقف إدخال دفعات جديدة      | رطوبة > 70%     |
| أخلِ المنطقة وسجّل الحادث       | افصل التيار واستخدم CO₂     | حريق صغير       |
| اتصل بالإسعاف عند الحاجة        | افصل التيار وقدّم الإسعافات | إصابة عامل      |

### نظام 5S

نظّم المواد، وحدد مكان كل أداة، ونظّف يومياً. وحّد الإجراءات، ثم راقب الالتزام باستمرار.

يُنفذ تفتيش شهري للمعدات، مخارج الطوارئ، مطافئ CO₂، الإسعافات، منطقة الحجر، وحاويات النفايات. تُسلَّم النفايات الخطرة لجهة مرخّصة عند امتلاء الحاوية 80% أو كل 6–12 شهراً.
