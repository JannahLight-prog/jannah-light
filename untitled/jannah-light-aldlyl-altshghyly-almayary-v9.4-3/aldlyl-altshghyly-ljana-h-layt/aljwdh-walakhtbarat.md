# الجودة والاختبارات

## الجودة والاختبارات

تحدد هذه الصفحة طريقة فحص المواد والمصابيح. لا تنتقل أي مادة أو وحدة بين المراحل دون سجل نتيجة واضح.

### المسؤوليات وصلاحية القرار

| الدور         | مسؤولياته                                  | لا يملك صلاحية          |
| ------------- | ------------------------------------------ | ----------------------- |
| أمين الاستلام | العد، التحقق من العبوات، ووضع بطاقة الحالة | اعتماد مادة غير مفحوصة  |
| فاحص الجودة   | الفحص، القياس، وتسجيل القبول أو الرفض      | تعديل المواصفة المعتمدة |
| مشرف الإنتاج  | إيقاف الخط، عزل المنتجات، وتنفيذ التصحيح   | الإفراج عن دفعة مرفوضة  |
| مسؤول الجودة  | اعتماد العينة، إغلاق NCR، والإفراج النهائي | تجاوز عيب حرج           |

تستخدم ثلاث بطاقات حالة: **قيد الفحص** باللون الأصفر، و**مقبول** بالأخضر، و**مرفوض أو معزول** بالأحمر. لا توضع المادة غير المفحوصة في رف المواد المقبولة.

### فحص المواد الواردة

#### قبل فتح العبوة

1. طابق اسم المادة، الكمية، ورقم أمر الشراء مع الفاتورة.
2. سجل اسم المورد، رقم الدفعة، تاريخ الاستلام، وعدد الصناديق.
3. صوّر أي كسر أو بلل أو انبعاج قبل فتح الصندوق.
4. ضع المادة في منطقة **قيد الفحص** حتى تظهر نتيجة الفحص.

إذا خالف العدد الفاتورة، سجل الفرق فورًا. لا تدمج الدفعة مع مخزون سابق.

#### سحب العينة

اسحب عينات موزعة من بداية الصندوق ووسطه ونهايته. افحص 10 قطع على الأقل للدفعات الصغيرة. افحص 1% على الأقل للدفعات الكبيرة، وبحد أقصى 50 قطعة.

العيب الحرج يوقف قبول الدفعة مهما كان حجم العينة. تشمل العيوب الحرجة تلف العزل، أو غياب المكوّن الوقائي المطلوب، أو قطبية خاطئة، أو كسر يمنع الاستخدام الآمن.

#### معايير القبول حسب المكوّن

| المكوّن          | افحص                                             | اقبل عند                                       | ارفض عند                                                 |
| ---------------- | ------------------------------------------------ | ---------------------------------------------- | -------------------------------------------------------- |
| رقائق LED        | اللون، التلف، لحام الأطراف، ورقم الدفعة          | تطابق اللون والمواصفة مع العينة المعتمدة       | بقع، تشققات، تفاوت ظاهر، أو غياب بيانات الدفعة           |
| لوحة PCB         | المسارات، الثقوب، طبقة الحماية، ومواضع المكوّنات | لا توجد مسارات مقطوعة أو قصر أو انحناء مؤثر    | تقشر، قطع في المسار، أو ثقوب غير مطابقة                  |
| الدرايفر         | الملصق، دخل الجهد، تيار الخرج، والحماية          | تطابق بياناته مع مواصفة موديل المصباح          | انتفاخ، تلف أسلاك، بيانات غير مطابقة، أو تشغيل غير مستقر |
| المشتت الحراري   | الوزن، الاستواء، فتحات التثبيت، والسطح           | يطابق الرسم أو العينة ولا يمنع التلامس الحراري | تشوه، شق، حافة حادة، أو فتحة تثبيت خاطئة                 |
| قاعدة E27 أو B22 | القلاوظ أو القفل، التلامس، والعزل                | تثبيت محكم وتلامس سليم دون حركة زائدة          | ارتخاء، صدأ، عزل متشقق، أو سن غير سليم                   |
| الغطاء والهيكل   | الشفافية، القفل، الخدوش، والتشقق                 | يركب دون ضغط أو فراغ مؤثر                      | تشقق، كسر، اصفرار شديد، أو عدم إحكام                     |

لا تعتمد شهادة أو ملصق المورد بدل الفحص الفعلي. تُحفظ شهادة المطابقة وورقة البيانات مع سجل الدفعة عند توفرهما.

### الفحص أثناء التجميع

#### نقطة الفحص الأولى: بعد تثبيت LED وPCB

يفحص العامل التثبيت قبل توصيل الدرايفر. يتحقق فاحص الجودة من عينة دورية كل ساعة ومن أول خمس وحدات بعد تغيير العامل أو المادة.

تحقق من الآتي:

* سطح الـPCB ملاصق للمشتت دون فراغ واضح.
* مادة التوصيل الحراري موزعة بكمية موحدة.
* براغي التثبيت مشدودة دون كسر اللوحة.
* قطبية LED والأسلاك مطابقة للعلامات على اللوحة.

#### نقطة الفحص الثانية: بعد اللحام والتوصيل

افحص كل وحدة بصريًا قبل الإغلاق. استخدم إضاءة كافية وعدسة عند الحاجة.

ارفض الوحدة أو أعد تشغيلها عند ظهور أي مما يأتي:

* جسر قصدير بين نقطتين.
* لحام باهت أو متشقق أو متحرك.
* سلك مكشوف أو عزل مقطوع.
* شد ميكانيكي على نقطة لحام.
* مسار أسلاك يلامس حافة حادة أو جزءًا ساخنًا.

يعاد إصلاح الوحدة مرة واحدة فقط. تعاد للوحدة نفسها كامل اختبارات المرحلة بعد الإصلاح. إذا تكرر العيب، تسجل كعيب وتتجه إلى تحليل السبب.

#### نقطة الفحص الثالثة: قبل الإغلاق والتعبئة

شغّل كل وحدة قبل تركيب الغطاء النهائي أو قبل التعبئة، حسب تصميم الموديل. تأكد من الإضاءة المنتظمة، وعدم الوميض، وعدم وجود صوت غير معتاد.

سجل نتيجة الوحدة في بطاقة الدفعة. اربط النتيجة برقم العامل، ورقم الدرايفر، ورقم دفعة LED.

### الاختبار النهائي

#### تجهيز محطة الاختبار

تُفحص أجهزة القياس في بداية كل وردية. تحقق من سلامة الأسلاك والقابس والحماية الأرضية. لا تستخدم جهازًا دون ملصق معايرة أو تحقق وظيفي ساري.

تتضمن المحطة، بحسب الاختبار المطلوب:

* مقياس القدرة والجهد والتيار.
* جهاز اختبار العزل أو الجهد العالي.
* حامل اختبار يناسب E27 أو B22.
* مؤقت وسجل نتيجة لكل دفعة.

#### اختبار كل وحدة

وصّل الوحدة في حامل آمن. شغّلها على جهد التشغيل الاسمي للموديل. انتظر حتى تستقر القراءة، ثم سجل الجهد والقدرة والتيار.

تقبل الوحدة عندما:

* تضيء فور التشغيل دون وميض مرئي.
* تكون القدرة ضمن ±10% من القدرة الاسمية المعتمدة.
* لا تصدر رائحة احتراق أو صوت طنين غير طبيعي.
* يثبت الغطاء والقاعدة دون حركة أو انفصال.

ضع الوحدة الفاشلة في صندوق العزل. لا تخلطها مع وحدات تنتظر إعادة العمل.

#### اختبار العينة من الدفعة

اختبر 5% من الدفعة، وبحد أدنى خمس وحدات، لاختبارات الإجهاد. وزع العينة على كامل وقت الإنتاج. لا تأخذها من أول الصندوق فقط.

| الاختبار        | طريقة التنفيذ                                  | معيار القبول                              | الإجراء عند الفشل      |
| --------------- | ---------------------------------------------- | ----------------------------------------- | ---------------------- |
| الحرق التشغيلي  | 265V لمدة ساعتين، ثم 170V لمدة ساعتين          | لا إطفاء، وميض، رائحة احتراق، أو تلف ظاهر | اعزل الدفعة وحلل السبب |
| التبديل         | 500 دورة تشغيل وإطفاء وفق زمن ثابت معتمد       | استمرار التشغيل الطبيعي بعد الدورات       | أوقف الإفراج عن الدفعة |
| السقوط          | ثلاث مرات من متر واحد وفق تغليف المنتج المعتمد | لا كسر أو انفصال أو فقد تشغيل             | راجع الهيكل والتغليف   |
| العزل           | 1440V AC على منصة اختبار مخصصة                 | مقاومة العزل ≥ 2 MΩ وتيار التسرب ≤ 5mA    | عزل فوري للوحدة وتحقيق |
| التداخل المبدئي | قرب راديو AM على مسافة 30–50 سم                | لا شوشرة قوية غير مقبولة                  | افحص الدرايفر والتأريض |

{% hint style="danger" %}
يقتصر اختبار الجهد العالي على شخص مدرب ومخول. استخدم منصة معزولة وحاجز حماية. افصل الطاقة قبل لمس الحامل أو الوحدة.
{% endhint %}

لا يمثل اختبار الراديو بديلًا عن اختبار توافق كهرومغناطيسي معتمد. استخدمه كفحص داخلي أولي فقط.

### قرار الدفعة وعدم المطابقة

احسب نسبة العيوب من الوحدات المفحوصة:

$$
\text{نسبة العيوب} = \frac{\text{عدد الوحدات المعيبة}}{\text{عدد الوحدات المفحوصة}} \times 100
$$

الهدف التشغيلي ألا تتجاوز نسبة العيوب 2%. عند تجاوز 5%، أو عند ظهور عيب حرج، طبق الإجراء التالي:

1. أوقف الخط وحدد آخر وحدة سليمة معروفة.
2. اعزل كل الوحدات المنتجة منذ تلك النقطة.
3. افتح تقرير عدم مطابقة NCR برقم الدفعة وتاريخها.
4. راجع المادة، إعداد اللحام، العامل، والأداة المستخدمة.
5. حدد السبب الجذري والإجراء التصحيحي والمسؤول والموعد.
6. أنتج عينة تحقق من 100 وحدة بعد التصحيح.
7. لا تستأنف الإنتاج إلا عند قبول 95 وحدة على الأقل وعدم وجود عيب حرج.

يجوز إعادة العمل للعيوب القابلة للإصلاح فقط. لا يسمح بإخفاء العيب أو تغيير الملصق أو خفض القدرة المعلنة لتصريف وحدة غير مطابقة.

### السجلات الإلزامية

احتفظ بالسجلات التالية لكل دفعة لمدة تحددها إدارة الجودة:

| السجل                  | الحقول الدنيا                                                     |
| ---------------------- | ----------------------------------------------------------------- |
| سجل فحص المواد الواردة | المورد، المادة، رقم الدفعة، الكمية، العينة، النتيجة، الفاحص       |
| بطاقة دفعة الإنتاج     | موديل المنتج، دفعات المكوّنات، العامل، وقت التجميع، الكمية        |
| سجل الاختبار النهائي   | رقم الدفعة، رقم الوحدة عند توفره، القراءات، النتيجة، الفاحص       |
| تقرير NCR              | وصف العيب، الصور، الكمية المعزولة، السبب، الإجراء، اعتماد الإغلاق |

لا تفرج عن المنتج النهائي دون ربط رقم المنتج أو رقم الدفعة بنتائج الاختبار ودفعات مكوّناته.
