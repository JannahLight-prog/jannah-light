# الجودة والاختبارات

## الجودة والاختبارات

### قبول المواد الواردة

تُفحص أول عينة من كل دفعة عند الاستلام. تُرفض الدفعة عند تجاوز حدود القبول أو ظهور عيب حرج.

| رفض فوري                   | شرط القبول                  | المكوّن   |
| -------------------------- | --------------------------- | --------- |
| غياب الشهادة أو كسر أو بقع | شهادة LM-80، فحص مجهري سليم | رقائق LED |
| مواصفة 85°C أو انتفاخ      | 105°C، عمر ≥ 5,000 ساعة     | المكثفات  |
| تشقق أو تشوه أو غياب RoHS  | UL94-V0 وثبات عند 120°C     | هيكل PC   |
| غياب عناصر الحماية         | Fusible وZener Diode        | PCB       |

حد العيوب المستهدف في العينة ≤ 2%. العيب الحرج يسبب الرفض الفوري. يُسجل الرفض بالصور ورقم الدفعة.

### الفحص الثلاثي

| معيار القبول                         | النطاق                     | المرحلة |
| ------------------------------------ | -------------------------- | ------- |
| لا جسور قصدير أو لحام بارد أو انزياح | كل PCB بعد اللحام والتنظيف | بصري    |
| تشغيل فوري، وقدرة ضمن ±10%           | كل وحدة قبل الإغلاق        | كهربائي |
| اجتياز الحرق والتبديل والسقوط        | عينة 5% من كل دفعة         | إجهاد   |

### اختبارات الإجهاد

* **Burn-in:** 265V لساعتين، ثم 170V لساعتين. ارفض الوميض أو الإطفاء أو السخونة الزائدة.
* **التبديل:** 500 دورة تشغيل وإطفاء. فشل عينة واحدة يستوجب عزل الدفعة وتحليل السبب.
* **السقوط:** ثلاث سقوطات من متر واحد. يجب بقاء الهيكل والناشر والدائرة سليمة.
* **العزل:** 1440V AC. مقاومة العزل ≥ 2 MΩ. تيار التسرب ≤ 5mA.
* **EMI:** افحص قرب راديو AM على بعد 30–50 سم. الشوشرة القوية تعني رفض العينة.

{% hint style="danger" %}
يُجرى اختبار الجهد العالي على منصة معزولة وتحت إشراف مباشر.
{% endhint %}

### عند تجاوز 5% عيوب

1. أوقف الخط واعزل الدفعة.
2. راجع إعدادات اللحام والمواد الواردة.
3. درّب العاملين المعنيين مجدداً.
4. اختبر دفعة من 100 وحدة.
5. استأنف فقط عند قبول 95% منها على الأقل.
