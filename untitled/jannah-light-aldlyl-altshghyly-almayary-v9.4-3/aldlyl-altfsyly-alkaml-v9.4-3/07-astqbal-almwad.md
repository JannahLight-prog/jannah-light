# 07 — استقبال المواد

## استقبال المواد

### قبل التفريغ

يستلم أمين المخزون الشحنة في منطقة الاستلام فقط. يطابق عدد الصناديق واسم المورد ورقم أمر الشراء مع الفاتورة وقائمة التعبئة. يصور العبوات من جميع الجوانب قبل فتحها عند وجود بلل أو ثقب أو كسر أو انبعاج.

لا يوقع المستلم قبولاً نهائياً قبل العد والفحص. يثبت توقيع الاستلام وصول الشحنة فقط، وليس مطابقة الجودة.

### تسجيل الدفعة

يفتح سجل استلام مستقل لكل مادة ولكل رقم دفعة. يسجل الحقول التالية دون استثناء:

| الحقل         | البيانات المطلوبة                          |
| ------------- | ------------------------------------------ |
| مرجع الاستلام | رقم متسلسل وتاريخ ووقت الوصول              |
| المورد        | الاسم ووسيلة الاتصال وبلد المنشأ عند توفره |
| المادة        | الاسم والمواصفة والموديل                   |
| الكمية        | الواردة والفاتورة والفرق الفعلي            |
| التتبع        | رقم أمر الشراء، رقم الدفعة، رقم الفاتورة   |
| الحالة        | قيد الفحص أو مقبول أو مرفوض أو ناقص        |
| المسؤول       | اسم المستلم وتوقيعه                        |

يلصق رقم الدفعة على كل صندوق أو حاوية داخلية. يمنع جمع دفعتين في حاوية واحدة.

### فتح العبوة وأخذ العينة

تفتح العبوة بحذر لتجنب إتلاف الملصقات أو الأكياس الواقية. تؤخذ عينة موزعة من أول الصندوق ووسطه وآخره. تفحص 10 قطع على الأقل للدفعات الصغيرة، و1% على الأقل للدفعات الكبيرة، وبحد أقصى 50 قطعة.

تنقل المادة إلى منطقة **قيد الفحص**. لا تصرف للإنتاج ولا تدخل رف المخزون المقبول حتى يسجل فاحص الجودة قرار القبول.

### الفروقات والأضرار

عند وجود نقص، سجل العدد الناقص وصور العبوة والمحتوى. عند وجود تلف نقل، افصل القطع المتضررة وصورها وأبلغ المورد أو الناقل وفق شروط الطلب.

إذا كان رقم الدفعة مفقوداً، أو المواصفة غير قابلة للتحقق، تبقى المادة معزولة. لا يعالج النقص أو العيب بالاستبدال الشفهي أو بتغيير بطاقة المادة.

### الإغلاق

بعد قرار الجودة، ينقل أمين المخزون المواد المقبولة إلى موقعها المحدد ويحدث الرصيد. تحفظ الفاتورة وقائمة التعبئة وصور التلف وتقرير الفحص تحت مرجع الاستلام نفسه.
