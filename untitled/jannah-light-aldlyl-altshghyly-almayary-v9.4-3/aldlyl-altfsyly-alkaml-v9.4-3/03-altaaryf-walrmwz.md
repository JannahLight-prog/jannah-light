# 03 — التعاريف والرموز

## التعاريف والرموز

| المصطلح أو الرمز  | التعريف التشغيلي                                                                                           |
| ----------------- | ---------------------------------------------------------------------------------------------------------- |
| LED               | صمام ثنائي باعث للضوء. يستخدم كمصدر الإضاءة في المصباح.                                                    |
| LED Chip SMD 2835 | رقاقة LED سطحية بقياس 2.8 × 3.5 مم. تحدد مواصفتها اللون واللومن وCRI والجهد وbinning والعمر.               |
| Driver            | دائرة تغذية تحول دخل الشبكة إلى خرج مناسب للـLED. لا يخلط درايفر مصباح AC 220–240V مع درايفر شرائط DC 12V. |
| PCB               | لوحة دائرة مطبوعة تثبت عليها المكوّنات وتربطها كهربائياً.                                                  |
| Heat Sink         | مشتت حراري من الألمنيوم ينقل حرارة الـLED بعيداً عن اللوحة.                                                |
| E27               | قاعدة لولبية بقطر اسمي 27 مم.                                                                              |
| B22               | قاعدة بحربة بقفل جانبي.                                                                                    |
| QC                | مراقبة الجودة. تشمل الفحص، القياس، القبول، الرفض، والسجل.                                                  |
| IQC               | فحص الجودة للمواد الواردة قبل إدخالها إلى المخزون المقبول.                                                 |
| BOM               | قائمة المواد المعتمدة لموديل محدد وكمياتها ومواصفاتها.                                                     |
| FIFO              | أقدم دخولاً أول خروجاً. تستخدم أقدم دفعة مقبولة أولاً.                                                     |
| NCR               | تقرير عدم مطابقة يفتح عند وجود عيب أو مخالفة للمواصفة.                                                     |
| CAPA              | إجراء تصحيحي ووقائي يعالج السبب ويمنع تكراره.                                                              |
| AQL               | حد قبول العيوب في عينة الفحص. الهدف التشغيلي للورشة لا يتجاوز 2%.                                          |
| ESD               | تفريغ كهرباء ساكنة قد يتلف مكوّنات LED وPCB.                                                               |
| Burn-in           | تشغيل عينة تحت ظروف محددة للكشف المبكر عن العيوب.                                                          |
| Hi-Pot            | اختبار قوة العزل الكهربائي بجهد مرتفع على منصة آمنة.                                                       |

### رموز الحالات

* **أخضر:** مادة أو منتج مقبول للاستخدام أو الشحن.
* **أصفر:** قيد الفحص. يمنع صرفه للإنتاج.
* **أحمر:** مرفوض أو معزول. يمنع خلطه بالمخزون السليم.

لا تستخدم اختصاراً غير معرف في هذه الصفحة أو في مواصفة الموديل.
