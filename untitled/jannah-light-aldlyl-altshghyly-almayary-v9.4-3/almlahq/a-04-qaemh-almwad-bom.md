# A-04 — قائمة المواد BOM

## قائمة المواد BOM

{% hint style="warning" %}
هذه مواصفات تخطيطية. لا تبدأ الإنتاج قبل اعتماد التصميم الكهربائي ونتائج الاختبار لكل موديل.
{% endhint %}

### المكونات الإلكترونية

| المكوّن           | المواصفة المقترحة                  | الكمية لكل مصباح | تحقق قبل الاعتماد                           |
| ----------------- | ---------------------------------- | ---------------: | ------------------------------------------- |
| LED Chip SMD 2835 | `2.8 × 3.5 × 0.7 mm`، عالي الكفاءة |            18–24 | اللون، اللومن، CRI، الجهد، binning          |
| Driver            | `220–240V AC`، تيار ثابت           |                1 | تيار الخرج، PF، العزل، الحماية الحرارية     |
| PCB               | FR4 ثنائي الطبقات، سماكة `1.6 mm`  |                1 | سماكة النحاس، Thermal Vias، التصميم الحراري |
| أسلاك التوصيل     | `22–24 AWG`، عازل PVC              |              2–3 | الطول، تحمل الحرارة، القطبية                |

**توزيع مبدئي لرقائق LED:** `9W = 18`، `12W = 20`، `18W = 24`. يعتمد العدد النهائي بعد اختبار القدرة والحرارة واللومن.

### المكونات الميكانيكية

| المكوّن       | المواصفة المقترحة         | الكمية | تحقق قبل الاعتماد                 |
| ------------- | ------------------------- | -----: | --------------------------------- |
| Heat Sink     | ألمنيوم 1060 بزعانف       |      1 | الوزن، الأبعاد، الأداء الحراري    |
| قاعدة E27/B22 | PBT مقاوم للحرارة أو خزف  |      1 | الثبات، التماس، تحمل الحرارة      |
| هيكل المصباح  | PC أو ABS مقاوم للأشعة UV |      1 | مقاومة اللهب والثبات الحراري      |
| الناشر الضوئي | PP أو PMMA                |      1 | التجانس، النفاذية، مقاومة الصدمات |

**أبعاد مبدئية للمشتت:** `9W = 60 mm`، `12W = 70 mm`، `18W = 80 mm`، `24W = 90 mm`. تقبل فقط بعد اختبار حراري موثق.

### مواد التجميع والتغليف

| المادة             | المواصفة أو الاستهلاك المقترح | تحقق قبل الاعتماد                  |
| ------------------ | ----------------------------- | ---------------------------------- |
| غراء سيليكون حراري | `0.15–0.20 g` لكل مصباح       | التوصيل الحراري وثبات التجميع      |
| قصدير لحام         | Sn63Pb37 أو SAC305            | المطابقة ومتطلبات السلامة          |
| Isopropanol        | نقاوة `99%`                   | توافقه مع عملية التنظيف            |
| علبة كرتون         | علبة مفردة مطبوعة             | رقم الدفعة والقدرة واللون والقاعدة |
| ملصق               | 1–2 ملصق لكل مصباح            | وضوح البيانات وثبات الطباعة        |
| فوم حماية          | قطعة واحدة لكل علبة           | مقاومة الصدمات أثناء الشحن         |
